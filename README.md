# DOPASTA Pro 公式紹介サイト

HTML・CSS・JavaScriptで動作する、アプリ本体とは独立した紹介サイトです。外部フォント・解析・Cookie・CDNライブラリを使用しません。

## ローカルで見る

このディレクトリで `python3 -m http.server 8080` を実行し、http://localhost:8080 を開きます。ビルドは不要です。

## GitHub Pages

1. GitHubの Settings → Pages → Build and deployment → Source で **GitHub Actions** を選びます。
2. このリポジトリの `main` にpushすると、`.github/workflows/pages.yml` がサイトを公開します。
3. 別名のブランチを使う場合は、ワークフローの `branches` を変更してください。

相対パスを使用し、リポジトリ名付きURLにも対応しています。ローカルの修正のみでは公開先へ反映されません。

## 編集する場所

- `index.html`：紹介文、ナビゲーション、FAQ、アプリへの導線
- `style.css`：ロゴ由来の配色、レイアウト、文字、表示イメージ
- `script.js`：スクロール演出、答えの確認と4段階評価の体験、集中画面のプレビュー
- `assets/`：既存アプリ由来のロゴ・アイコン・背景
- `assets/materials/`：アプリ内のオリジナル教材表紙3点。出版社の表紙画像ではありません

ヘッダーの「ログイン・新規登録」、冒頭と末尾の「アプリを開く」は `https://163.43.183.198/` へ移動します。URLを変える場合は `index.html` の該当URLをまとめて更新してください。

紹介サイトのタイマー・対戦グラフ・レポート・状態・通知は表示イメージです。実際のアカウントや学習記録と連動しません。復習体験は初回の4段階評価に応じた間隔と達成演出を表示しますが、記録・復習予定を保存しません。flowstate MODEの体験も画面表示のみで、計測・マイク使用・通知許可は行いません。

JavaScript無効時も本文・ナビ・FAQが表示されます。動きを減らす設定ではスクロール演出と状態の波紋を停止します。

## 動作確認

初回は `npm install` と `npx playwright install chromium` を実行し、`npm test` で確認します。Chromeがインストール済みなら `PLAYWRIGHT_CHANNEL=chrome npm test` を使えます。テストサーバーにはPython 3が必要です。

320・390・768・1024・1440pxで、横はみ出し、画像、4段階評価・紙吹雪、集中画面の終了とフォーカス復帰、更新内容とFAQの順序、既存のロゴ演出を確認します。実際のiPhone・iPadや本番サーバーへの配信・通知・音声再生の確認は含みません。

## グラフの表示

対戦グラフはアプリ本体の `src/NetworkTimeline.tsx` の `RankChart` と、`src/style.css` の `network-ranks` を参照した同じ構造です。順位・時間・目盛り付きの棒・名前・状態を共通の行に配置し、日間／週間の高さは180px、月間は95px。チーム内・チーム対抗・全体の切替はローカルで動作します。

レポートはアプリ本体の `src/ReportPage.tsx` の棒グラフと同じく、各日の時間・目盛り・曜日を表示します。狭い画面ではグラフ内部を横スクロールできます。公開ユーザーの実データを取得する機能は追加していません。表示用の値はHTML内に固定し、紹介ページから認証APIや個人データに接続しません。

## スクロール演出の負荷対策

ロゴを一文字ずつ描く動きと逆スクロールで戻る動きを維持し、位置の測定は起動・サイズ変更・内容変更時にまとめています。スクロール中は測定値を再利用し、変化した要素だけを更新します。ロゴの移動は座標の再配置ではなく変形で処理します。スマホ幅・タッチ操作主体のデバイスではロゴと背景のぼかしを無効にし、画面外でロゴの更新を続けないようにしています。OSで動きを減らす設定をしている場合は完成状態を表示します。

スマホでは、文字を画面サイズに合わせて事前に画像化し、1文字ずつ小さな画像に分割して使います。スクロール中のSVGの輪郭描画・Canvasの描き直しは行わず、文字の表示範囲・透明度とカメラの変形だけを更新します。画像は生成元で最大2048px、表示用の各文字は256px以内に制限し、アドレスバーによる高さだけの変化では画像を作り直しません。拡大・左から右への追従・最後に全体を表示する動きと、逆スクロールは維持しています。画像化できない環境では従来のSVGへ戻ります。

`tests/mobile-brand.spec.ts` は画面密度3倍のスマホ相当条件で、スクロール中のSVG更新・Canvas再描画が0回であること、画像の再利用とサイズ上限、動きを減らす設定を確認します。

`tests/scroll-performance.spec.ts` で、CPU処理を遅くしたChromeによる320px・390px・1440px幅のスクロール、位置の測り直しがないこと、画面外でロゴを更新しないことを確認します。実機のiPhone／Safariによる計測ではありません。
